# مزایای زبان راست

برخی از نقاط قوت منحصربه‌فرد زبان راست عبارت‌اند از:

## ایمنی حافظه در زمان کامپایل (compile time memory safety)

کلاس‌های کاملی از باگ‌های حافظه در زمان کامپایل جلوگیری می‌شوند:

- متغیرهای مقداردهی‌نشده (uninitialized variables) وجود ندارند.
- آزادسازی دوباره (double-free) وجود ندارد.
- استفاده پس از آزادسازی (use-after-free) وجود ندارد.
- اشاره‌گرهای `NULL` وجود ندارند.
- اصلاحیه: mutex های قفل‌شده فراموش‌شده وجود ندارند.
- رقابت داده‌ای (data race) بین threadها وجود ندارد.
- بی‌اعتبارسازی iterator (iterator invalidation) وجود ندارد.

## بدون رفتار نامعین در زمان اجرا (undefined runtime behavior)

آنچه یک دستور راست انجام می‌دهد هرگز نامشخص رها نمی‌شود:

- دسترسی به آرایه با بررسی محدوده (bounds check) انجام می‌شود.
- سرریز عدد صحیح (integer overflow) به‌صورت تعریف‌شده رفتار می‌کند (panic یا wrap-around).

## ویژگی‌های زبان مدرن

به‌اندازه زبان‌های سطح بالاتر بیانگر و ارگونومیک است:


- اصلاحیه: enumها و تطبیق الگو (pattern matching).
- اصلاحیه: generics (نوع‌های عمومی).
- اصلاحیه: FFI بدون سرباره (no overhead FFI).
- انتزاع‌های بدون هزینه (zero-cost abstractions).
- خطاهای عالی کامپایلر.
- مدیر وابستگی داخلی (built-in dependency manager).
- پشتیبانی داخلی برای تست.
- پشتیبانی عالی از Language Server Protocol.
