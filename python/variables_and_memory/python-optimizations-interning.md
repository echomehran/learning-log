## بهینه‌سازی‌های پایتون: درون‌سپاری

پیش‌تر دیدیم که ارجاع‌های مشترک به‌طور خودکار توسط پایتون ایجاد می‌شوند:


```python
a = 10
b = 10
print(id(a))
print(id(b))
```

    1968827120
    1968827120


توجه کنید که `a` و `b` به همان شیء ارجاع می‌دهند.

اما مثال زیر را در نظر بگیرید:


```python
a = 500
b = 500
print(id(a))
print(id(b))
```

    1935322088624
    1935322089008


همان‌طور که می‌بینید، متغیرهای `a` و `b` به همان شیء اشاره **نمی‌کنند**!

این به این دلیل است که پایتون اشیاء عدد صحیح را در بازهٔ [-5, 256] از پیش ذخیره می‌کند.

برای مثال:


```python
a = 256
b = 256
print(id(a))
print(id(b))
```

    1968834992
    1968834992


و


```python
a = -5
b = -5
print(id(a))
print(id(b))
```

    1968826640
    1968826640


ارجاع یکسانی دارند.

به این کار **درون‌سپاری** می‌گویند: پایتون اعداد صحیح در بازهٔ [-5, 256] را **درون‌سپاری** می‌کند.

اعداد صحیح در بازهٔ [-5, 256] اساساً اشیاء **تک‌نمونه** هستند.


```python
a = 10
b = int(10)
c = int('10')
d = int('1010', 2)
```


```python
print(a, b, c, d)
```

    10 10 10 10



```python
a is b
```




    True




```python
a is c
```




    True




```python
a is d
```




    True



همان‌طور که می‌بینید، همهٔ این متغیرها به روش‌های مختلفی ایجاد شدند، اما چون شیء عدد صحیح با مقدار 10 مانند یک تک‌نمونه رفتار می‌کند، همهٔ آن‌ها در نهایت به **همان** شیء در حافظه اشاره کردند.
