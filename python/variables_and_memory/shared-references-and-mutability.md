## ارجاع‌های مشترک و تغییرپذیری

مجموعهٔ زیر یک ارجاع مشترک بین متغیرهای `my_var_1` و `my_var_2` ایجاد می‌کند


```python
my_var_1 = 'hello'
my_var_2 = my_var_1
print(my_var_1)
print(my_var_2)
```

    hello
    hello



```python
print(hex(id(my_var_1)))
print(hex(id(my_var_2)))
```

    0x24c9144ca08
    0x24c9144ca08



```python
my_var_2 = my_var_2 + ' world!'
```


```python
print(hex(id(my_var_1)))
print(hex(id(my_var_2)))
```

    0x24c9144ca08
    0x24c9144fab0


اگر نوع متغیر تغییرپذیر است مراقب باشید!

در اینجا یک لیست (`my_list_1`) ایجاد می‌کنیم و یک متغیر (`my_list_2`) می‌سازیم که به همان شیء لیست ارجاع می‌دهد:


```python
my_list_1 = [1, 2, 3]
my_list_2 = my_list_1
print(my_list_1)
print(my_list_2)
```

    [1, 2, 3]
    [1, 2, 3]


همان‌طور که می‌بینیم آن‌ها آدرس حافظهٔ یکسانی دارند (ارجاع مشترک):


```python
print(hex(id(my_list_1)))
print(hex(id(my_list_2)))
```

    0x24c9144fc48
    0x24c9144fc48


حال لیست ارجاع‌شده توسط `my_list_2` را تغییر می‌دهیم:


```python
my_list_2.append(4)
```

نکته: 
`my_list_2` تغییر کرده است:


```python
print(my_list_2)
```

    [1, 2, 3, 4]


و چون `my_list_1` به همان شیء لیست ارجاع می‌دهد، آن نیز تغییر کرده است:


```python
print(my_list_1)
```

    [1, 2, 3, 4]


همان‌طور که می‌بینید، هر دو متغیر هنوز همان ارجاع را به اشتراک می‌گذارند:


```python
print(hex(id(my_list_1)))
print(hex(id(my_list_2)))
```

    0x24c9144fc48
    0x24c9144fc48


### پشت صحنه با مدیر حافظهٔ پایتون
----

از چند درس قبل به یاد بیاورید:


```python
a = 10
b = 10
```


```python
print(hex(id(a)))
print(hex(id(b)))
```

    0x7559eaf0
    0x7559eaf0


آدرس حافظهٔ یکسان!!

انجام این کار برای پایتون ایمن است زیرا اشیاء عدد صحیح **تغییرناپذیر** هستند.

بنابراین، حتی اگر `a` و `b` در ابتدا همان آدرس حافظه را به اشتراک می‌گذاشتند، هرگز نمی‌توانیم مقدار `a` را با «تغییر» مقدار `b` تغییر دهیم.

تنها راه تغییر مقدار `b` تغییر ارجاع آن است، که هرگز بر `a` تأثیر نخواهد گذاشت.


```python
b = 15
```


```python
print(hex(id(a)))
print(hex(id(b)))
```

    0x7559eaf0
    0x7559eb90


با این حال، برای اشیاء تغییرپذیر، مدیر حافظهٔ پایتون این کار را انجام نمی‌دهد، زیرا این کار **ایمن** نخواهد بود.


```python
my_list_1 = [1, 2, 3]
my_list_2 = [1, 2 , 3]
```

همان‌طور که می‌بینید، اگرچه دو متغیر «محتویات» یکسانی به آن‌ها تخصیص داده شده است، آدرس‌های حافظه یکسان نیستند:


```python
print(hex(id(my_list_1)))
print(hex(id(my_list_2)))
```

    0x24c9146c5c8
    0x24c913c6848
