## تغییرپذیری اشیاء

برخی از انواع اشیاء داخلی پایتون (که به‌عنوان انواع داده نیز شناخته می‌شوند) **تغییرپذیر** هستند.

یعنی محتویات داخلی (حالت) شیء در حافظه می‌تواند تغییر کند.


```python
my_list = [1, 2, 3]
print(my_list)
print(hex(id(my_list)))
```

    [1, 2, 3]
    0x1cf6ab5b208



```python
my_list.append(4)
print(my_list)
print(hex(id(my_list)))
```

    [1, 2, 3, 4]
    0x1cf6ab5b208


همان‌طور که می‌بینید، آدرس حافظهٔ *my_list* **تغییر نکرده** است.

اما **محتویات** *my_list* از *[1, 2, 3]* به *[1, 2, 3, 4]* تغییر کرده است.

از طرف دیگر، این را در نظر بگیرید:


```python
my_list_1 = [1, 2, 3]
print(my_list_1)
print(hex(id(my_list_1)))
```

    [1, 2, 3]
    0x1cf6abd55c8



```python
my_list_1 = my_list_1 + [4]
print(my_list_1)
print(hex(id(my_list_1)))
```

    [1, 2, 3, 4]
    0x1cf6ab56888


توجه کنید که در اینجا آدرس حافظهٔ *my_list_1* **تغییر کرده** است.

این به این دلیل است که الحاق دو شیء لیست *my_list_1* و *[4]* محتویات *my_list_1* را تغییر نداد — بلکه یک شیء لیست جدید ایجاد کرد و *my_list_1* را دوباره به این شیء جدید ارجاع داد.

به‌طور مشابه با اشیاء **دیکشنری** که آن‌ها نیز انواع **تغییرپذیر** هستند.


```python
my_dict = dict(key1='value 1')
print(my_dict)
print(hex(id(my_dict)))
```

    {'key1': 'value 1'}
    0x1cf6abdcdc8



```python
my_dict['key1'] = 'modified value 1'
print(my_dict)
print(hex(id(my_dict)))
```

    {'key1': 'modified value 1'}
    0x1cf6abdcdc8



```python
my_dict['key2'] = 'value 2'
print(my_dict)
print(hex(id(my_dict)))
```

    {'key1': 'modified value 1', 'key2': 'value 2'}
    0x1cf6abdcdc8


یک‌بار دیگر می‌بینیم که در حالی که **محتویات** دیکشنری را تغییر می‌دهیم، آدرس حافظهٔ *my_dict* تغییر نکرده است.


حال نوع دنبالهٔ تغییرناپذیر را در نظر بگیرید: **تاپل**

تاپل تغییرناپذیر است، بنابراین عناصر نمی‌توانند اضافه، حذف یا جایگزین شوند.


```python
t = (1, 2, 3)
```

این تاپل **هرگز** به‌طور کلی تغییر نخواهد کرد. این سه عنصر دارد، اعداد صحیح 1، 2 و 3. این موضوع تا زمانی که ارجاع **t** تغییر نکند، باقی خواهد ماند.

اما تاپل زیر را در نظر بگیرید:


```python
a = [1, 2]
b = [3, 4]
t = (a, b)
```

حال، **t** هنوز تغییرناپذیر است، یعنی شامل ارجاعی به شیء **a** و شیء **b** است. **این** تا زمانی که ارجاع **t** دوباره تخصیص داده نشود، هرگز تغییر نخواهد کرد.

**با این حال**، عناصر **a** و **b** خودشان تغییرپذیر هستند.


```python
a.append(3)
b.append(5)
print(t)
```

    ([1, 2, 3], [3, 4, 5])


مشاهده کنید که محتویات **a** و **b** **تغییر کرده‌اند**!

بنابراین تغییرناپذیری می‌تواند کمی ظریف‌تر از صرفاً فکر کردن به این باشد که چیزی هرگز نمی‌تواند تغییر کند.

تاپل **t** تغییر **نکرد** — این شامل دو عنصر است که ارجاع‌های **a** و **b** هستند. و این تغییر نخواهد کرد. اما چون عناصر ارجاع‌شده خودشان تغییرپذیر هستند، به‌نظر می‌رسد که تاپل تغییر کرده است.

اما این‌طور نیست — این تمایز ظریف اما مهم است که درک شود!
