### بولین‌ها: عملگرهای بولین

روشی که عملگرهای بولین ``and`` و ``or`` در واقع کار می‌کنند در پایتون کمی متفاوت است:

#### روش OR

نکته: ``X or Y``: اگر X falsy باشد، Y را برمی‌گرداند، در غیر این صورت X را ارزیابی و بازمی‌گرداند.


```python
'' or 'abc'
```




    'abc'



```python
0 or 100
```




    100



```python
[] or [1, 2, 3]
```




    [1, 2, 3]



```python
[1, 2] or [1, 2, 3]
```




    [1, 2]



باید توجه کنید که مقدار درستی ``Y`` هرگز حتی هنگام ارزیابی نتیجهٔ ``or`` در نظر گرفته نمی‌شود!

تنها عملوند چپ مهم است.

البته، اگر Y بازگردانده شود ارزیابی خواهد شد — اما مقدار درستی آن بر نحوهٔ محاسبهٔ ``or`` تأثیری ندارد.

احتمالاً متوجه خواهید شد که این بدان معناست که اگر ``X`` بازگردانده شود، ``Y`` ارزیابی نمی‌شود — اتصال کوتاه!!!

می‌توانستیم (تقریباً!) عملگر ``or`` را خودمان به این شکل بنویسیم:

```python
def _or(x, y):
    if x:
        return x
    else:
        return y
```

```python
print(_or(0, 100) == (0 or 100))
print(_or(None, 'n/a') == (None or 'n/a'))
print(_or('abc', 'n/a') == ('abc' or 'n/a'))
```

    True
    True
    True

چرا گفتم تقریباً؟

برخلاف عملگر ``or``، تابع ``_or`` ما همیشه x و y را ارزیابی می‌کند (آن‌ها به‌عنوان آرگومان پاس داده می‌شوند) — بنابراین اتصال کوتاه نداریم!

```python
1 or 1/0
```




    1

```python
_or(1, 1/0)
```

#### روش AND

نکته: `X and Y`: اگر X falsy باشد، X را برمی‌گرداند، در غیر این صورت Y را ارزیابی و بازمی‌گرداند.

یک‌بار دیگر توجه کنید که مقدار درستی Y هرگز هنگام ارزیابی `and` در نظر گرفته نمی‌شود، و اینکه ``Y`` فقط در صورتی ارزیابی می‌شود که نیاز باشد بازگردانده شود (اتصال کوتاه).

```python
s1 = None
s2 = ''
s3 = 'abc'
```

```python
print(s1 and s1[0])
print(s2 and s2[0])
print(s3 and s3[0])
```

    None
    
    a

```python
print((s1 and s1[0]) or '')
print((s2 and s2[0]) or '')
print((s3 and s3[0]) or '')
```

    
    
    a

این تکنیک همچنین برای بازگرداندن هر مقدار پیش‌فرضی در صورتی که ``s`` یک رشتهٔ خالی یا None باشد کار خواهد کرد:

```python
print((s1 and s1[0]) or 'n/a')
print((s2 and s2[0]) or 'n/a')
print((s3 and s3[0]) or 'n/a')
```

    n/a
    n/a
    a
