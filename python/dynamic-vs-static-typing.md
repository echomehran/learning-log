### تایپ داینامیک

پایتون به‌صورت داینامیک تایپ شده است.

این بدان معناست که نوع یک متغیر صرفاً نوع شیئی است که نام متغیر به آن اشاره می‌کند (به آن ارجاع می‌دهد). خود متغیر هیچ نوع مرتبطی ندارد.


```python
a = "hello"
```


```python
type(a)
```




    str




```python
a = 10
```


```python
type(a)
```




    int




```python
a = lambda x: x**2
```


```python
a(2)
```




    4




```python
type(a)
```




    function



همان‌طور که از مثال‌های بالا می‌بینید، نوع متغیر `a` در طول زمان تغییر کرد — در واقع این نوع صرفاً نوع شیئی بود که `a` در آن لحظه به آن ارجاع می‌داد. هیچ نوعی هرگز به خود نام متغیر متصل نشد.
