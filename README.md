## Repository Structure

```text
python/                Python exercises and experiments
postgresql/            PostgreSQL and SQL practice
git/                   Git experiments and notes
```

## What You'll Find Here

The repository contains:

- Small exercises
- Focused experiments
- Jupyter notebooks
- Concept demonstrations
- Technical notes
- References and examples created while learning

The goal is not to collect every piece of code I write, but to preserve useful parts of my learning process.

## Philosophy

Learn → experiment → understand → document.

I prefer small, focused examples over large collections of disconnected practice files.

This repository is a long-term archive and may evolve as my interests and studies change.
